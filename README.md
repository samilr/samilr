### 🧭 Overview

I'm a software engineer with **8+ years** building and running production systems for telecom, banking and fuel retail in the Dominican Republic. I work across the backend in **Python, Java, C# / .NET and Node.js / TypeScript**, and today I build **production AI systems**.

- 🤖 **AI systems (telecom):** multi-agent pipelines, **MCP servers** used by other systems, **RAG** over vector databases, and LLM evaluation, with cloud and local models (Azure OpenAI, OpenAI, Ollama).
- ⛽ **Fuel retail:** selected the stack for and led a Station Control & IoT platform running across **80+ service stations**, plus a POS rollout to **300+ devices**, card payments and national e-invoicing. I also built a **Python FastAPI** API serving about **420K requests/month**.
- 🏦 **Banking:** **Java / Quarkus** microservices with **Apache Kafka** on **Red Hat OpenShift** for regulated workloads.
- 📡 **Telecom backend & integrations:** Java / Spring Boot, Node.js / NestJS and Groovy / Grails services for a prepaid activation platform with biometric verification.
- 🛠️ I work hand in hand with AI tools to improve my work.
- 🌎 Spanish (native) · English (C1).
